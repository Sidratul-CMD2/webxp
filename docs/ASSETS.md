# Asset provenance manifest

Every image in the application is **original artwork created for this project**, drawn in code from geometric primitives by [`scripts/generate-assets.mjs`](../scripts/generate-assets.mjs). No Microsoft image, icon, font, sound or third-party emulator asset is included, extracted or hotlinked. Period design guidance (R1 in RESEARCH.md: colourful, dimensional, upper-left lighting, 16/32/48 px sizes) informed the *style* only; it is not a redistribution licence and nothing was copied from it.

Regenerate all artwork with `node scripts/generate-assets.mjs` (deterministic: same output every run).

## Licence and provenance (applies to every generated file)

| Field | Value |
|---|---|
| Creator | This project (generated by `scripts/generate-assets.mjs`) |
| Source | Original SVG geometry and gradients written in that script; no traced or embedded raster data |
| Licence / permission | Original work of this project; no third-party rights involved |
| Modifications | None after generation; files are written directly by the script |
| Fallback | Icons: `iconUrl()` in `src/ui/icons.tsx` falls back to `folder.svg` for an unknown name. Wallpapers: Display Properties offers "(None)" with a solid colour |
| Runtime loading | Bundled by Vite into `dist/assets/` and served from the same origin; no remote requests |

## Fonts

No font files are bundled or redistributed.

| Role | Stack | Notes |
|---|---|---|
| UI text | `Tahoma, Arial, sans-serif` (11 px at 100%) | Uses a locally installed Tahoma when present (present on this macOS 27.2 build machine and on Windows). Otherwise Arial. Rendering differs by platform: macOS anti-aliasing is softer than XP's ClearType-off default. |
| Window titles, Start "start" label, headings | `'Trebuchet MS', Tahoma, Arial, sans-serif` | Local Trebuchet MS when present |
| Browser pages | `Verdana, Tahoma, Arial, sans-serif` | Local fonts only |

## Sounds

None. Sound effects are an optional, post-release feature (PRODUCT.md), and the simulation plays no audio. The Sounds applet and the tray volume control only store simulated settings and say so.

## Known fidelity gaps from asset substitution

- Icons are original approximations of the XP style, so silhouettes and colours differ from Microsoft's artwork. The Start glyph, browser icon and Recycle Bin are deliberately different designs.
- Hillside approximates the *feel* of the default XP wallpaper but is a different, simpler image.
- Screens use system fonts, so glyph shapes and metrics depend on the host (see VISUAL.md and `docs/REFERENCE.md`).
